# SmartDevice-Next(Kotlin移行)

Android拡張機能アプリの進化版になります。

## 概要

- 画面フィルターを用いて、輝度をOSの最低値以下まで下げたり、暖色にしたりできます
- 内部音量の監視を行い、閾値以上のデシベル量を検知した場合に自動減音します

## 使用技術

- **言語**: Kotlin(Javaから移行)
- **最小SDK**: API 29
- **主な使用機能**:
  - Foreground Service
  - Overlay(SYSTEM_ALERT_WINDOW)
  - MediaProjection(RECORD_AUDIO)
  - マテリアルデザイン3(Google)
  - Navigation/Fragment

## 開発の経緯

元々Javaで開発していたアプリを、Kotlinへ移行しました。
(コードの簡潔さと、null安全性などが両立され、Javaより有用に感じました。)
移行と同時に、リファクタリングや機能追加を実施しています。

## 主な追加機能

- ナイトモード（画面輝度低下フィルター）が1時間で自動停止するようになりました。
- 爆音キャンセラー使用時に、現在の内部音声のデシベル量や、オーディオビジュアライザーを表示できるようにしました。
